Property 'status' is missing in type

Sửa lại đoạn code lỗi: Thêm status. Để khi chạy code không còn gạch đỏ vì object payment2 đã đúng với kiểu Payment Data

Bài D3. Bẫy index

Bước 1: Dự đoán kết quả
Mảng sau bài D2: 

const transactionIds: string[] = [
  "TXN001",
  "TXN002",
  "TXN003",
  "TXN004"
];

Vì mảng có 4 phần tử, chỉ số (index) bắt đầu từ 0 nên:
TXN001 có index = 0
TXN002 có index = 1
TXN003 có index = 2
TXN004 có index = 3

Khi dự đoán, sử dụng lệnh: transactionIds[4] để trả về undefined

Bước 2: Chạy code để kiểm tra

const transactionIds: string[] = [
  "TXN001",
  "TXN002",
  "TXN003",
  "TXN004"
];

console.log(transactionIds[4]);

Kết quả sau khi chạy code:

undefined

Giải thích:
Vì mảng có 4 phần tử nên khi truy cập transactionIds[4] sẽ tìm phần tử thứ 5, nhưng mảng không có phần tử thứ 5, sẽ trả kết quả là undefined

  }
];

- In amount của giao dịch đầu tiên
