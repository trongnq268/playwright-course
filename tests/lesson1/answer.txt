2. git status: là câu lệnh để kiểm tra những thứ đã thay đổi sau khi commit thành công
Ví dụ:
GẤP LẠI những bộ quần áo đã có trong tủ-> thực hiện commit -> thực hiện gọi git status -> báo ko thay đổi gì :modify
GẤP quần áo MỚI  và cất tủ ->thực hiện commit thành công-> thực hiện gọi git status -> báo những bộ quần áo vừa được thêm mới lần đầu (những thứ thay đổi so với cái cũ): untrack file

Kiểm tra trạng thái của project.
- File nào đã sửa
- File nào chưa được add
- File nào chuẩn bị commit
----------------------------------------

3. git add: là hạnh động đặt quần áo vào trong 1 ô tủ đựng quần áo
** git add: là hành động thêm câu lệnh đã code (từng file)
** git add. : là hành động thêm tất cả các câu lệnh đã code (toàn bộ)
----------------------------------------

4. git commit: đưa 1 hoặc nhiều ô tủ quần áo vừa thay đổi tới chỗ tủ

Lưu lại các thay đổi thành một phiên bản (Version).

Ví dụ:

git commit -m "Create lesson01"


----------------------------------------

5. git clone: mua 1 cái tủ mới về với toàn bộ giống hệt với tủ gốc (hình dáng, màu sắc, số lượng, quần áo..) copy y hệt nhưng ở 1 vị trí khác tủ gốc

Tải một repository từ GitHub về máy tính.

Ví dụ:

git clone https://github.com/username/project.git


----------------------------------------

6. git push: Cất quần áo vào tủ (hoàn thành)

Đẩy code từ máy tính lên GitHub.

Ví dụ:

git push origin main


----------------------------------------

7. git checkout

Chuyển sang branch khác hoặc tạo branch mới từ nhánh gốc (main). Cho phép lấy thông tin từ nhánh gốc và chỉnh sửa thoải mái với nhánh miows . Tuyệt đối k động vào nhánh gốc
